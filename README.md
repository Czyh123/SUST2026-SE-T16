## 2. 程序工作原理

本项目基于 **PERT（计划评审技术）** 和 **CPM（关键路径法）**，结合资源平衡算法，对“景游园智导”项目进行工期估算、关键路径识别及人员资源优化分配。主要工作流程如下：

### 2.1 核心算法
1.  **三点估算法 (PERT)**：
    *   通过乐观时间 ([optimistic](file://e:\i-tech\123124.py#L0-L0))、最可能时间 ([most_likely](file://e:\i-tech\123124.py#L0-L0)) 和悲观时间 ([pessimistic](file://e:\i-tech\123124.py#L0-L0)) 计算每个任务的期望工期：
        $$ TE = \frac{O + 4M + P}{6} $$
2.  **关键路径法 (CPM)**：
    *   **正推法 (Forward Pass)**：计算每个任务的最早开始时间 (`ES`) 和最早结束时间 (`EF`)。
    *   **逆推法 (Backward Pass)**：计算每个任务的最晚开始时间 (`LS`) 和最晚结束时间 (`LF`)。
    *   **时差计算**：总时差 `Float = LS - ES`。时差为 0 的任务构成**关键路径**，决定项目总工期。
3.  **资源平衡与调度**：
    *   采用**贪心策略**结合**最小堆 (Min-Heap)** 算法。
    *   在不延长项目总工期的前提下，优先复用已空闲的人员，若无可用的空闲人员则新增人员。
    *   目标：计算出完成项目所需的**最少人数及其任务分配方案**。

### 2.2 可视化输出
*   **PERT 网络图**：展示任务依赖关系，红色节点/边标识关键路径。
*   **甘特图**：展示各人员在时间轴上的任务分配情况。

## 4. 编译/运行说明

### 4.1 运行程序
在终端或命令行中执行以下命令：

```bash
python pert_project.py
```

### 4.2 操作指南
程序启动后，提供三种数据输入方式：

1.  **一键加载默认数据**：
    *   输入 `1`，系统将自动加载预设的“景游园智导”项目任务数据（包含需求调研、架构设计、算法开发等 11 个任务）。
2.  **手动输入任务**：
    *   输入 `2`，按提示依次输入任务名称、乐观/最可能/悲观时间、前置任务（多个前置任务用逗号分隔）。输入 `q` 结束录入。
3.  **JSON 文件导入**：
    *   输入 `3`，提供 JSON 文件路径。JSON 格式需包含 [name](file://e:\i-tech\123124.py#L0-L0), [optimistic](file://e:\i-tech\123124.py#L0-L0), [most_likely](file://e:\i-tech\123124.py#L0-L0), [pessimistic](file://e:\i-tech\123124.py#L0-L0), `predecessors` 字段。

### 4.3 查看结果
*   程序将在控制台输出：
    *   各任务期望工期及关键任务标记。
    *   关键路径序列。
    *   项目总工期。
    *   最少所需人数。
*   当提示 `显示图表？(y/n)` 时：
    *   输入 `y`：弹出两个窗口，分别显示 **PERT 网络图** 和 **人员任务分配甘特图**。
    *   输入 [n](file://e:\i-tech\01_b_图搜索算法\puzzle_maze_problem.py#L0-L0)：仅显示文本结果并退出。
