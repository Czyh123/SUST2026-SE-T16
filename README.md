# 项目简介
本项目是《软件工程课程实践》实验 5 的完整实现，基于 PERT（计划评审技术）与 CPM（关键路径法）实现了软件项目进度的自动化分析。

**解决的核心问题：**
- 替代人工计算，自动化完成任务工期、时差、关键路径的复杂推导
- 在保证项目最短工期不变的前提下，自动计算所需最少人力并生成任务分配表
- 通过甘特图与网络图实现项目进度的可视化

# 环境依赖
本程序使用 Python 3 开发，需要安装以下第三方库：

```bash
pip install networkx matplotlib prettytable
```

```bash
python pert_scheduler.py
```

# 功能说明
## 输入功能
- 手动添加任务：支持输入任务名称、工期、前置依赖关系
- 数据持久化：支持将当前项目数据保存为 JSON 文件，支持后续加载继续编辑
- 多起点 / 终点支持：天然支持多个起始任务或多个结束任务，无需额外配置

## 处理功能
- 关键路径计算：自动计算每个任务的最早开始 (ES)、最早结束 (EF)、最晚开始 (LS)、最晚结束 (LF)、总时差
- 项目工期计算：自动推导项目的最短总工期
- 资源优化分配：在保证项目最短工期不变的前提下，采用贪心算法错峰调配非关键任务，计算所需最少人数，并生成完整的任务分配安排

## 输出功能
- 专业控制台表格：使用 PrettyTable 生成带边框的对齐表格，展示所有任务参数与分配结果
- 甘特图可视化：直观展示每个人的任务安排，关键任务标红显示
- 时序网络图：按执行顺序从左到右分层展示任务依赖关系，关键路径高亮

# 程序工作原理
1. **依赖建模**
   - 使用 NetworkX 构建有向无环图 (DAG)，节点代表任务，边代表依赖关系。
2. **时间参数计算**
   - 拓扑排序：对任务进行拓扑排序，保证计算顺序的正确性
   - 正推法：从起始任务开始，正向计算每个任务的 ES 和 EF
   - 逆推法：从结束任务反向计算，得到每个任务的 LS 和 LF
   - 时差计算：通过 LS - ES 计算任务的总时差，时差为 0 的任务即为关键任务
3. **资源分配算法**
   - 采用基于最晚开始时间 (LS) 的贪心策略：
     - 按 LS 升序排序任务，优先保障关键任务
     - 对每个任务，尝试分配给现有人员，只要能在最晚结束时间 (LF) 前完成即可
     - 若现有人员无法满足，则新增人员
   - 最终得到不延期前提下的最少人力配置
4. **可视化**
   - 甘特图：使用 Matplotlib 绘制，展示人员任务时间线
   - 网络图：自定义拓扑分层布局，保证左到右为执行时序，直观清晰
