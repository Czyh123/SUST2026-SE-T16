# PERT 项目进度分析与任务分配系统（前端版）

## 项目简介
本项目是一款基于浏览器的 PERT/IPO 项目进度分析工具。可自动计算项目工期、关键路径、任务时差，并优化人员分配以满足最短工期要求。所有逻辑均在浏览器端完成，无需后端支持。

## 编译 / 运行说明
- 本程序为纯 HTML + JavaScript 前端应用，无需编译。
- 运行步骤如下：
  1. 将 `solve.html` 文件保存到本地。
  2. 使用任意现代浏览器（如 Chrome、Firefox、Edge 等）直接打开该文件即可运行。
  3. 无需额外依赖，所有逻辑均在浏览器端完成。

## 程序工作原理

### 1. 任务数据处理
- 接收用户输入的任务名称、三点估算时间（乐观 O / 最可能 M / 悲观 P）、前置任务关系。
- 校验数据合法性（无重复任务名、无循环依赖、时间值为正数等）。
- 按 PERT 公式 $(O + 4M + P) / 6$ 计算每个任务的期望工期。

### 2. PERT 核心计算
- 拓扑排序：基于前置任务关系生成无环任务执行序列。
- 时间参数计算：推导每个任务的最早开始/完成时间（ES/EF）、最晚开始/完成时间（LS/LF）、时差。
- 关键路径识别：筛选时差为 0 的任务组成关键路径，关键路径总时长即为项目最短总工期。

### 3. 人员分配优化
- 以关键路径工期为约束，从最少人数开始遍历验证。
- 通过回溯搜索算法，在“任务不可拆分、单人单任务”规则下，寻找满足最短工期的最少人员配置。
- 输出任务-人员-时间的分配方案，生成可视化时序图与分配表。

### 4. 可视化展示
- 将计算结果（关键路径、任务时序、人员分配、统计数据）以图表/表格形式直观呈现，关键任务标红突出。
